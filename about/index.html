ABOUT / 关于

你好，这里是 gptbert。

一个记录软件实践、工具探索与学习过程的地方。

为什么写

项目做完之后，许多有价值的细节会很快被忘记。把问题、取舍和验证过程写下来，可以让下一次实践有一个更好的起点。

文章会随着理解的变化继续修订；代码和公开实验放在 GitHub。

如何关注

可以订阅 RSS，或直接查看文章列表。

SITE NOTE / 站点说明

文章由 GitHub 管理，通过 Cloudflare Pages 发布到 gptbert.com。
