Frequently Asked Questions

1. How do I set up an API key?

Open the “Models” page and enter your provider's API key in the API Key field.

2. How do I set up the API address?

Open the “Models” page and enter the endpoint address provided by your service provider in the API Address field.

3. What if the book source list is empty?

Open the “Book Sources” page and tap the + button in the upper-right corner to add a source.

4. How do I clear my settings?

You can delete the relevant settings in the app, or uninstall and reinstall the app.
